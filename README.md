# nix-config

Personal NixOS + Home Manager configuration for the `luynar` host: Hyprland
(Lua config), Catppuccin Mocha everywhere, fish + Starship, kitty, waybar,
rofi, dunst.

## Layout

```
flake.nix                      inputs, systems, formatter
hardware-configuration.nix     generated by nixos-generate-config — do not edit
modules/
  core/
    theme.nix                  single source of truth for the color palette
    desktop.nix                base NixOS system config (boot, users, audio, greetd)
    hosts/luynar.nix           wires everything into nixosConfigurations.luynar
  features/
    <name>.nix                 one file per program/service (nixos + home-manager modules)
    files/                     static configs shipped verbatim or templated with theme colors
Wallpapers/                    images for the rofi wallpaper switcher
```

Modules are exposed as flake outputs (`flake.modules.nixos.*` /
`flake.modules.homeManager.*`, via `flake-parts.flakeModules.modules`) and
composed in `modules/core/hosts/luynar.nix`. To add a feature: create
`modules/features/<name>.nix`, define `flake.modules.{nixos,homeManager}.<name>`,
import the file in `flake.nix`, and reference the module from the host file.

## Theming

Colors flow from `modules/core/theme.nix` (`config.theme.*`) into every
consumer — either as native Nix option values (kitty, starship, hyprland) or
via `lib.replaceStrings` templating into vendored config files (dunst,
waybar, rofi, hyprshot). Change a color once in `theme.nix`, rebuild, done.

## Vendored / patched tools

A few third-party scripts are shipped under `modules/features/files/` instead
of pulled straight from nixpkgs, because we need to tweak their behavior:

- `hyprshot/hyprshot` — nixpkgs' `hyprshot` (screenshot tool) with the
  `slurp` region-select call given a themed border/dim instead of upstream's
  unstyled default. Built in `hyprland.nix` (`hyprshotScript`/`hyprshot`
  derivation), mirroring nixpkgs' own package recipe.
- `kitty/search.py` — kitty's scrollback search kitten (`ctrl+f`), not
  bundled with kitty itself.
- `rofi/scripts/*.sh` — power menu and wallpaper switcher, adapted from the
  adi1090x rofi theme collection.

## Keybinds worth remembering

| Key                  | Action                                    |
| --------------------- | ------------------------------------------ |
| `SUPER + S`            | App launcher (rofi)                        |
| `SUPER + SHIFT + W`     | Wallpaper switcher                         |
| `SUPER + SHIFT + S`     | Screenshot: select an area (clipboard only) |
| `PRINT`                | Screenshot: full screen (clipboard only)    |
| `SUPER + SHIFT + Q`      | Power menu                                 |
| `SUPER + L`             | Lock screen                                |

Full list lives in `modules/features/hyprland.nix` (`bind` array).

## Rebuild

```
sudo nixos-rebuild switch --flake .#luynar
```

Wallpapers and any other files this flake reads must exist on disk before
rebuilding — if the repo is under git, new files also need `git add` (nix
flakes only see tracked/staged files when run from inside a git repo).

## Formatting

```
nix fmt
```

Runs `nixfmt` over the tree. `hardware-configuration.nix` is generated and
intentionally left unformatted/untouched.
